개발 중인 서비스 안내

머니노트는 출시 준비 중입니다. 일반 앱 진입점은 시작 화면을 제공합니다. 별도 개발 검증 화면에서는 가상 기록을 로컬 DB에 저장하고 테스트 CSV 저장·공유창, 임시 파일 복사·정리 및 비밀번호 기반 암호화 백업·복원을 확인합니다. 이 백업 검증은 가상 계좌·분류·거래·휴지통에 한정됩니다. 실제 사용자용 가계부 화면, 예산·반복 규칙을 포함한 전체 백업 및 운영 CSV 광고는 아직 제공하지 않습니다. 별도 개발 화면에는 기본 꺼짐의 오류 진단 선택 기능을 추가했으며 승인된 고정 테스트 오류 1건의 서버 수신과 전송 해제 후 재시작 상태를 확인했습니다. 동의 전 보고 처리와 오프라인 동의 철회는 추가 검증 대상입니다. Google Mobile Ads SDK는 개발 검증을 위해 포함되어 있으며, 별도 개발용 화면에서 공식 테스트 광고를 요청합니다. 아래 출시 예정 기능의 설명은 개발 계획이며 현재 작동하는 기능을 뜻하지 않습니다. 실제 배포 전에 데이터 처리와 SDK 설정을 검증하고 이 문서 및 시행일을 갱신합니다.

1. 현재 데이터 처리

현재 앱은 회원가입이나 로그인, 금융기관 연결, 사용자 금융정보의 서버 전송 기능을 제공하지 않습니다. Google Analytics는 포함되어 있지 않습니다. Firebase Core와 Crashlytics SDK는 포함되어 있으며 오류 보고는 기본 꺼짐입니다. Firebase 초기화는 별도 개발 화면에서 확인하며, 보고를 끄는 것이 Firebase 관련 통신 전체를 차단한다는 뜻은 아닙니다. 광고 SDK는 포함되어 있으나 일반 시작 화면에서는 광고 초기화·요청을 호출하지 않습니다. 개발용 테스트 화면에서는 광고 제공을 위해 SDK가 기기·접속·진단 정보를 처리할 수 있습니다. 관리용 Firebase·AdMob 프로젝트를 등록한 사실만으로 앱이 이용자의 데이터를 전송하지는 않습니다.

이 페이지는 GitHub Pages에서 제공됩니다. 페이지 방문 시 호스팅 제공자가 IP 주소와 접속 관련 정보를 처리할 수 있습니다. 이 페이지에는 운영자가 추가한 분석 스크립트나 광고가 없습니다. 자세한 사항은 GitHub 개인정보처리방침을 참고하세요.

2. 출시 예정: 기기 내 금융 기록

출시 버전은 사용자가 입력한 계좌 이름·유형·잔액, 수입·지출·이체 내역, 금액·날짜·분류·메모, 예산, 반복 예정, 표시 설정을 기기 내 앱 전용 저장소에서 처리하도록 설계합니다. 목적은 거래 기록, 예산과 자산·부채 현황 계산입니다. 운영자의 서버에 금융 기록을 업로드하거나 광고·진단 데이터에 포함하지 않는 것이 개발 방침입니다.

회원가입·투자 관리·금융기관 자동 연동·클라우드 동기화는 제공 범위에 포함하지 않습니다. 기기 저장소와 운영체제 보호를 사용하며 별도 데이터베이스 암호화나 앱 잠금 기능을 제공한다고 보장하지 않습니다.

3. 출시 예정: 백업과 CSV 내보내기

백업은 사용자가 지정한 비밀번호로 암호화하고 직접 선택한 위치에 저장하는 방식으로 준비합니다. CSV는 암호화되지 않은 파일이며 내보내기 전에 포함되는 항목과 주의사항을 안내할 예정입니다. 저장 위치로 클라우드 서비스를 선택하면 해당 서비스의 정책이 적용됩니다. 운영자는 사용자가 내보낸 파일에 접근하거나 대신 삭제할 수 없습니다.

앱 데이터가 운영체제의 자동 클라우드 백업이나 기기 이전에 포함되지 않도록 제외 설정을 추가했습니다. 실제 기기 이전 환경에서의 검증은 아직 완료하지 않았습니다.

4. 출시 예정: 광고와 동의

Google AdMob 광고는 연령 구간에 따른 앱 자체 제외 없이 CSV 저장 요청마다 준비를 시도하며, 저장이 성공한 뒤 완료 화면으로 이동하는 시점에만 표시하도록 준비합니다. 첫 실행 제외나 하루 횟수 제한은 두지 않습니다. 동의 SDK의 요청 허용 여부를 확인하며, 저장 실패·취소, 앱 종료 시에는 광고를 표시하지 않습니다. 광고가 준비되지 않거나 요청이 허용되지 않아도 CSV 저장을 완료할 수 있도록 설계합니다. 광고 노출을 구분하기 위한 생년월일이나 연령 구간을 수집하지 않습니다.

광고 SDK가 적용되면 Google은 광고 제공·측정·부정 이용 방지를 위해 IP 주소, 광고 및 앱 상호작용, 성능·오류 정보, 광고 ID 등 기기 식별자를 수집·공유할 수 있습니다. IP 주소로 대략적인 위치가 추정될 수 있으며, 이는 위치 권한을 이용한 정밀 위치 수집과 구분됩니다. 금융 기록·계좌명·메모를 광고 요청에 넣지 않을 계획입니다.

적용 지역과 법률에 따라 Google UMP를 통해 광고 관련 선택을 제공하고, 필요한 경우 선택을 다시 변경할 수 있는 진입점을 마련합니다. Google Analytics는 추가하지 않을 계획입니다. 현재 개발 검증 버전은 google_mobile_ads 9.1.0, Android Google Mobile Ads 25.4.0, UMP 4.0.0을 사용합니다. 운영 동의 흐름과 실제 배포 설정에 따른 수집 항목은 배포 전에 검증합니다.

5. 출시 예정: 선택형 오류 진단

현재 개발 검증 버전은 Firebase Core 4.14.0과 Crashlytics 5.3.0을 포함합니다. 오류 진단 전송은 기본 꺼짐이며 별도 개발 화면에서 사용자가 선택할 수 있습니다. 동의를 거부해도 핵심 가계부 기능을 이용할 수 있도록 설계합니다. 처리 대상은 앱·운영체제·기기 정보, 오류 추적 정보와 설치 관련 식별자이며 금융 기록, 메모, 계좌 이름과 원문 로그는 포함하지 않을 계획입니다.

선택을 끄면 앱의 새 진단 기록을 중지하고 미전송 보고 삭제를 요청합니다. SDK 자동 보고 해제는 다음 앱 시작부터 완전히 적용되며, 이미 전송 중이거나 전송된 보고를 즉시 취소하지는 못합니다. 앱이 추가하는 보고는 고정 오류 코드만 사용하고 오류 원문·사용자 메모·계좌명을 넣지 않습니다. SDK의 자동 네이티브 보고와 삭제 동작은 출시 전 추가 검증 대상입니다. 이미 전송된 데이터의 보관·삭제는 제공자의 처리 절차가 적용됩니다. Firebase의 현재 안내에 따르면 Crashlytics 오류 추적 및 관련 식별자는 90일 보관 후 삭제 절차가 시작됩니다. Firebase 개인정보 및 보관 안내

6. 문의 시 처리하는 정보

이용자가 이메일 문의를 보내면 답변용 이메일 주소, 문의 내용 및 직접 첨부한 자료를 문의 확인·답변 목적으로 처리합니다. 문의를 보내지 않으면 해당 정보를 받지 않습니다. 금융 거래 원본, 비밀번호, 신분증 등 불필요한 민감정보는 보내지 마세요.

문의 정보는 처리가 끝나고 보관 필요가 없어진 경우 삭제합니다. 법령에 따른 보관 의무가 있는 경우 그 범위에서 보관하며, 구체적인 문의 보존 기간은 출시 전 확정해 안내합니다. 이메일 제공자의 서비스 운영을 위한 처리에는 해당 제공자의 정책도 적용됩니다.

7. 외부 처리 및 국외 처리

예정된 광고·진단 서비스 제공자는 Google이며, 이 페이지의 호스팅 제공자는 GitHub입니다. 서비스 제공 과정에서 미국 등 국외에서 데이터가 처리될 수 있습니다. 실제 앱에 적용되는 서비스별 이전 항목·목적·국가·시점과 방법·보존 기간 및 이용자의 선택 방법은 출시 전 SDK와 계약 조건을 확인하여 이 문서에 구체적으로 반영합니다. 현재 가계부 금융 기록을 국외 전송하는 앱 기능은 없습니다.

8. 이용자의 선택과 삭제

출시 버전에는 기록 수정·삭제와 앱 데이터 초기화 기능을 준비합니다. 기기 내부 데이터 삭제와 외부에 저장한 CSV·백업 삭제는 별개입니다. 앱 삭제 후의 데이터 복원 가능 여부와 자동 백업 제외 동작은 배포 전 확인하여 안내합니다. 저장 매체의 물리적 완전 소거를 보장하지 않습니다.

문의와 관련된 개인정보 열람·정정·삭제·처리정지 요청은 아래 이메일로 보내실 수 있습니다. 운영자가 보유하지 않은 기기 내부 금융 기록은 대신 조회하거나 복구할 수 없습니다.

9. 권한과 보호 조치

출시 버전에서는 연락처, SMS, 전화, 정밀 위치, 카메라, 사진, 알림 권한을 직접 요청하지 않을 계획입니다. 파일은 시스템 파일 선택기로 접근하고 전체 저장소 접근 권한은 사용하지 않습니다. 광고·동의·진단을 위한 인터넷 접근 및 SDK가 추가하는 권한은 실제 배포 구성으로 확인하여 안내합니다.

10. 변경 및 연락처

기능과 데이터 처리 방식이 달라지면 이 페이지와 앱 내 안내를 갱신합니다. 현재 문서는 출시 준비 안내이며 최종 출시 개인정보처리방침의 시행일은 아직 정하지 않았습니다.
